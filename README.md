# se-301-storage-and-databases (student solutions)

Reference answers for the SE 301 auto-checks. Push this folder as one GitHub repository.

- GitHub repo name: `se-301-storage-and-databases` (same for all tasks)
- GitHub dir: the `github_dir` column in `solutions-map.csv`
- GitHub file: the `github_file` column in `solutions-map.csv`

Folders are grouped by topic, not by week, so a task can move between weeks without a change here.
Each topic folder holds several task files. The checker copies its own seed files (`main_*.sql`) before each check.

The four AI tasks are graded by hand and have no file here.
Week 4 tasks 00 to 02 need a server with real accounts (users and grants).
